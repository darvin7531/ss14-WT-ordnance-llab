# Ordnance Lab — Space Stories CM14

Веб-приложение для Оружейного техника (OT): расчёт кастомной взрывчатки, химии и эффективности против T3 в Space Stories CM14.

## Возможности

- быстрый подбор готовых боеприпасов;
- ручной конструктор смеси;
- open-grid симуляция `ExplosionSystem` вместо упрощённой линейной формулы `Power / Falloff`;
- расчёт blast damage по T3 с `ExplosionArmor`;
- режимы последовательных и объединённых взрывов;
- шрапнель `25 Piercing / AP20`;
- пошаговое производство химии;
- энциклопедия реагентов: вклад каждой 1u, роль, когда полезен/вреден, цвет и special FireEntity;
- анализ текущей смеси: что реально работает после caps и что стало балластом/косметикой;
- `Industry Freezer` для параформальдегида;
- безопасное разбиение ANFO / nitroglycerin на партии;
- PWA/offline через Service Worker;
- адаптивный интерфейс для телефона и ПК.

Данные и формулы сверены с public master Space Stories CM14 на commit `a85baeafd79b5c07fd64aad1196a6258dd8b6e25`.

## GitHub Pages

Деплой полностью автоматический через `.github/workflows/pages.yml`.

После каждого push в `main` workflow:

1. собирает чистую статическую папку `_site`;
2. настраивает GitHub Pages;
3. загружает Pages artifact;
4. публикует сайт.

Приложение использует hash routing (`#/quick`, `#/combat`, `#/chemistry`), поэтому серверные rewrite-правила не нужны.

## Локальный запуск

```bash
python -m http.server 8080
```

После этого открой `http://localhost:8080`.

## Ограничения боевого симулятора

Open-grid карта воспроизводит распределение intensity для пустой сетки. Стены, airtight blockers и разрушение геометрии пока не моделируются интерактивно. Щиты и специальные состояния ксено учитываются только там, где это явно реализовано в интерфейсе.
